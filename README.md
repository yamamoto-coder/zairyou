# 問屋さん — 建築資材検索システム

塗料・木材・壁紙・金物など建築資材の価格と購入履歴を、
請求書のPDF・写真から自動で読み取って検索できる社内ツールです。

## 主な機能

- 請求書(PDF/写真)のドロップで明細を自動読み取り(Google Gemini)
- 材料名・メーカー・性質での横断検索(税別/税込 切替)
- 材料ごとの価格履歴と、Web検索に基づく値上がり予測
- 仕入先に料金表を読み取ってもらい、返送ファイルで反映する受信箱
- データのバックアップ/復元(ブラウザ内保存)

## アプリのアドレス

<https://yamamoto-coder.github.io/zairyou/>

更新が見えないときは Ctrl+F5 で強制再読み込みしてください。

## 初期設定

1. アプリの「データ管理 → 読み取りエンジン」で Gemini の APIキーを入力して保存
   (キーは https://aistudio.google.com/apikey で無料発行。
    キーは各利用者のブラウザ内にのみ保存されます)
2. 「接続テスト」で ✓ Gemini を確認
3. ホームに戻り、請求書を取り込んで検索

## 注意

- APIキーをこのリポジトリのファイルに書き込まないでください
- 購入データ・キーは各ブラウザ内保存です。PC入替時は
  「データ管理 → バックアップ」で書き出し/読み込みしてください
