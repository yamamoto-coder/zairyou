# 問屋さん — 建築資材検索システム

建築資材全般(構造材・内装材・設備材・仕上材)の価格と購入履歴を、
請求書のPDF・写真から自動で読み取って検索できる社内ツールです。
専門27業種(とび・土工から清掃施設まで)で扱う資材に対応しています。

## 主な機能

- 請求書(PDF/写真)のドロップで明細を自動読み取り(Google Gemini)
- 材料名・メーカー・性質での横断検索(税別/税込 切替)
- AIが商品をWeb調査して付ける検索タグ・商品画像・電子カタログ
- 材料ごとの価格履歴と、Web検索に基づく値上がり予測
- 発注カート(仕入先ごとにまとめ発注。コピー/LINE/メール)
- 仕入先に料金表を読み取ってもらい、返送ファイルで反映する受信箱
- データのバックアップ/復元(ブラウザ内保存)

## 初期設定

AI 読み取りの設定は管理者が行います。
新しいパソコンで使い始めるときは、管理者に設定を依頼してください。
設定内容は各パソコンのブラウザ内にのみ保存されます。

設定が済んだら、ホームで請求書を取り込んで検索できます。
