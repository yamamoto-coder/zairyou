## 概要(4000文字以内)

```
「問屋さん」は、建築資材(構造材・内装材・設備材・仕上材)の価格と購入履歴を、請求書から自動で読み取って検索できる、建設業向けの業務アプリです。とび・土工から内装仕上、清掃施設まで、専門27業種で扱う資材に対応しています。

■ こんな会社に
・見積のたびに「この材料、前はいくらで買った?」を探している
・価格の記憶がベテラン担当者の頭の中にしかない
・請求書のファイルはあるが、品目ごとの価格まで整理できていない

■ できること
・請求書・見積書の取り込み
  カメラで撮るか、写真・PDFを選ぶだけ。AIが品名・数量・単価・仕入先を読み取って明細にします。
・価格と購入履歴の横断検索
  材料名・メーカー・性質から検索。税別/税込の切り替え、仕入先ごとの比較、価格の推移グラフ。
・値上がりの見通し
  Web上の情報をもとに、資材ごとの価格傾向をAIが要約します。
・発注カート
  検索結果から仕入先ごとにまとめて発注文を作成。共有シート・LINE・メールで送信。
・料金表の受信箱
  仕入先に料金表を読み取ってもらい、返送ファイルを取り込むと最新価格として反映。
・書類の原本保管
  取り込んだPDF・写真はクラウドに保存。あとから原本を確認できます。
・社内で共有
  データは会社ごとにサーバー保存。社員アカウントを追加すれば、全員が同じ価格情報を見られます。

■ 料金
初期費用・月額ともに0円。アプリ内課金はありません。

■ ご利用にあたって
・利用には会社アカウントが必要です(アプリ内から無料で登録できます)。
・請求書の読み取りにはインターネット接続が必要です。
・書類の内容はAIによる読み取りのために外部のAIサービスへ送信されます。詳しくはプライバシーポリシーをご覧ください。

運営: 株式会社KYOEI
```
